# An-Explainable-Hybrid-Deep-Learning-Framework-for-Intrusion-Detection-Using-SLA-FS-
An explainable hybrid intrusion detection framework that integrates CNN, GRU, and the proposed SHAP-LIME Aggregated Feature Selection (SLA-FS) method to improve detection accuracy, reduce feature dimensionality, and provide transparent, interpretable cybersecurity predictions using Explainable AI (XAI).
