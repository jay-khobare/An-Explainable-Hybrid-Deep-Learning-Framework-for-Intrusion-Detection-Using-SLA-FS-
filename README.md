# An-Explainable-Hybrid-Deep-Learning-Framework-for-Intrusion-Detection-Using-SLA-FS-
An explainable hybrid intrusion detection framework that integrates CNN, GRU, and the proposed SHAP-LIME Aggregated Feature Selection (SLA-FS) method to improve detection accuracy, reduce feature dimensionality, and provide transparent, interpretable cybersecurity predictions using Explainable AI (XAI).


#🚀 Key Features:

🔍 Novel SLA-FS Algorithm combining SHAP (global explanations) and LIME (local explanations) for explainable feature selection.
🧠 Hybrid CNN-GRU Architecture for learning both spatial and temporal characteristics of network traffic.
📊 Explainable AI (XAI) integration using SHAP and LIME.
⚡ Feature dimensionality reduction for faster training and inference.
🎯 High-performance intrusion detection with improved precision, recall, F1-score, and ROC-AUC.
📈 Visualization of feature importance, model explanations, confusion matrices, and performance metrics.
